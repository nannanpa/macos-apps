# macos-apps

MA Bin 的 macOS 小工具集合。每个应用一个子目录，安装包（DMG）发布在各自的 GitHub Releases。

## 应用列表

| 应用 | 简介 | 下载 |
|---|---|---|
| [行程助手](trip-assistant/) | 粘贴一段会议通知，自动解析时间/地点/标题，确认后写入 macOS 日历。支持中文模糊时间（"明天上午10点""4月7日18:30到8日18:30"）、会议名提炼、备注精简、基于位置的发车提醒。 | [Latest Release](https://github.com/nannanpa/macos-apps/releases/latest) |

## 系统要求

- Apple Silicon（arm64）Mac
- macOS 12 Monterey 及以上

## 安装方式

从对应应用的 Release 页下载 DMG，打开后把应用拖入 Applications 文件夹即可。
